# Игрофикатор

Игровой тренажёр школьных предметов для планшета. Первая тема — таблица умножения от 2 до 9.

Приложение сделано как PWA: открывается по ссылке, ставится иконкой на главный экран и работает без интернета. Каждый push в `main` проверяется тестами и публикуется на GitHub Pages.

## Как поставить на планшет (Android)

1. Откройте ссылку на игру в Chrome.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

Новая версия подтягивается сама при следующем запуске.

## Награды

Каждый правильный ответ приносит 1 монетку, каждая неправильная попытка отнимает 2 (ниже нуля баланс не опускается), а за 5 верных ответов подряд дают ещё 1. После каждой игры Катя открывает сундучок с предметом из коллекции текущей локации, а когда коллекция собрана, в сундучке 2 монетки. На монетки по очереди открываются новые локации на карте мира: Цирк, Городок (100), Парк слаймов (200), Школа (300) и Космос (400). Цены подобраны так, чтобы даже без единой ошибки на весь мир понадобилось не меньше 10 полных проходов таблицы; это проверяет тест экономики в `src/core/rewards.test.ts`. В каждой локации свой фон, свой персонаж и шесть предметов для коллекции. Локации и предметы описаны данными в `src/world/locations.ts`, персонажи — в `src/core/characters.ts`.

## Экран для родителя

Удерживайте шестерёнку в правом верхнем углу 1,5 секунды. Там карта знаний по таблице умножения, сохранение прогресса в файл и загрузка из файла (для переноса на другое устройство).

## Разработка

```sh
npm install
npm run dev      # локальный сервер
npm test         # тесты
npm run build    # сборка в dist/
```

## Как устроен код

- `src/core` — общее ядро: типы, повторение по ящикам Лейтнера, игровая сессия, награды, сохранение, персонажи, звуки.
- `src/topics` — модули тем. Тема описывает, что учить, как спросить, проверить и подсказать (`TopicModule` в `src/core/types.ts`).
- `src/exercises` — типы заданий. Сейчас есть только ввод числа (`NumberInput`).
- `src/world` — карта мира: локации, цены, коллекции предметов.
- `src/components` — персонажи-слаймы, карта мира и экран для родителя.

Новая тема — новый файл в `src/topics`. Новый тип задания — значение в `ExerciseKind` и компонент в `src/exercises`.
